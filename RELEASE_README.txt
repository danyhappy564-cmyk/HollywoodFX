HollywoodFX for SPT 4.1.5
=============================

ORIGINAL MOD / 원작
    Author  : SleepingPills
    Source  : https://github.com/SleepingPills/HollywoodFX
    License : MIT
    Also published on the SPT Forge.

THIS BUILD / 이 빌드
    An unofficial port of the above to SPT 4.1.5, by danyhappy564-cmyk.
    Fork    : https://github.com/danyhappy564-cmyk/HollywoodFX

    Nothing was added or redesigned. SPT 4.1 deobfuscated the game client, which
    renamed the types and members this mod binds to, so a 4.0 build no longer
    loads at all. This port updates those references and nothing else.

    상위 원작을 SPT 4.1.5에서 동작하도록 포팅한 비공식 빌드입니다.
    기능 추가나 변경은 없습니다. SPT 4.1이 클라이언트를 역난독화하면서 이 모드가
    참조하던 타입·멤버 이름이 전부 바뀌었고, 그래서 4.0 빌드는 아예 로드되지
    않습니다. 그 참조를 되살린 것이 전부입니다.

    Full change notes are in the fork's README.
    상세 변경점은 포크 README에 있습니다.

    Please direct praise, bug reports and feature requests to the original mod,

    이 모드의 설계와 이펙트, 에셋은 전부 원작자 SleepingPills의 것입니다.
    칭찬·버그 제보·기능 요청은 원작 쪽으로 부탁드립니다. 다만 4.1.5에서만
